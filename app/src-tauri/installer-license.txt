con/vert is free and open source
=================================

con/vert is open source software under the MIT License (full text below).
You may use, copy, change and share it, free of charge.

It is built on the source code of File Beaver, created and published by
DEVIOUSDEV101:

    https://github.com/DEVIOUSDEV101/file-beaver

Thank you, DEVIOUSDEV101, for creating File Beaver and sharing it as open
source. con/vert keeps everything File Beaver does with images and PDFs and
adds audio and video: format conversion, tempo and key detection, and audio
tools.

Audio and video are handled by FFmpeg (LGPL v3), installed alongside the app.
Key detection uses Spotify's Basic Pitch note model (Apache-2.0).
The licences of FFmpeg and every other component are in THIRD_PARTY_NOTICES.txt
and ffmpeg-LICENSE.txt in the install folder.
